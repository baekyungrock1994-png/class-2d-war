# 2D War Royale

배틀그라운드(PUBG) 스타일 2D 배틀로얄. 순수 HTML5 Canvas + JavaScript(ES 모듈), 빌드/개발 서버는 Vite. Firebase Realtime Database + Authentication으로 온라인 매치를 지원합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저가 뜨면 "혼자 연습(오프라인)" 또는 "온라인 매치" 선택 → 지도에서 낙하 지점 클릭 → "낙하 시작". WASD로 이동, 조준은 자동(가장 가까운 적), 스페이스바를 누르고 있으면 공격(기본은 주먹), R로 재장전, 숫자키 1~4로 보유 무기 전환, 5로 의료품 사용, G로 수류탄 투척.

## Firebase 설정 (온라인 매치에 필요)

1. `src/network/firebaseConfig.js`에 Firebase 콘솔의 웹 앱 설정값을 채워 넣습니다.
2. **Authentication** → Sign-in method → **익명(Anonymous)**을 활성화합니다. 로그인 화면 없이 닉네임만 입력하면 바로 플레이할 수 있도록(.io 게임 방식) 익명 인증으로 각 브라우저마다 조용히 식별자를 발급합니다.
3. **Realtime Database**를 만듭니다(Firestore 아님). 생성 후 나오는 `https://...firebasedatabase.app` 형태의 URL을 `firebaseConfig.js`의 `databaseURL`에 넣습니다.
4. Realtime Database → Rules 탭에 이 저장소의 [firebase-database-rules.json](firebase-database-rules.json) 내용을 붙여넣고 게시합니다. (호스트만 매치 상태/맵/스냅샷을 쓸 수 있고, 각 플레이어는 자기 로비/입력 항목만 쓸 수 있도록 제한합니다.)

이 설정이 안 되어 있어도 **혼자 연습(오프라인) 모드는 정상 동작**합니다 — `db`가 초기화되지 않으면 온라인 관련 기능만 비활성화되고 나머지는 그대로 동작하도록 만들어 두었습니다.

## 온라인 매치 구조

- **인증**: 별도 로그인 화면 없이, 페이지가 뜨는 순간 Firebase Authentication의 익명 로그인이 조용히 완료됩니다(.io 게임처럼). "온라인 매치" 버튼을 누르면 바로 닉네임 입력 화면으로 이동하고, 마지막으로 사용한 닉네임은 이 브라우저에 기억해뒀다가 다음에 자동으로 채워줍니다(수정 가능). 혼자 연습(오프라인) 모드는 이 설정이 없어도 그대로 동작합니다.
- **방(room)**: 5자리 코드로 생성/참가. 데이터는 `rooms/{roomId}` 아래에 저장됩니다: `hostId`, `status`(`lobby`→`playing`), `lobby/{uid}`(참가자 목록), `match`(`{map, round}` — 장애물/지형과 매치 회차 번호, 매치 시작·재시작 때마다 기록), `input/{uid}`(각 플레이어가 자기 조작 상태를 주기적으로 기록), `snapshot`(호스트가 전체 월드 상태를 주기적으로 방송).
- **재시작(같은 방 유지)**: 매치가 끝나도 방과 로비 인원은 그대로 유지됩니다. 호스트가 "다시하기"를 누르면 `match.round`가 새 값으로 바뀌면서 게스트들의 리스너가 이를 감지해 자동으로 새 낙하 화면으로 전환됩니다 — 방을 새로 만들거나 코드를 다시 공유할 필요가 없습니다.
- **호스트 권위 모델**: 방을 만든 사람의 브라우저가 곧 "서버" 역할을 합니다. 호스트는 기존 오프라인 로직을 그대로 실행하면서, 참가자들이 보낸 입력(`input/{uid}`)으로 그들의 캐릭터도 함께 시뮬레이션하고(봇처럼), 매 틱마다 전체 상태(`snapshot`)를 방송합니다.
- **참가자(게스트) — 클라이언트 예측**: 게스트도 자기 캐릭터만큼은 호스트와 똑같은 `Player` 클래스를 로컬에서 직접 시뮬레이션합니다. 그래서 이동·조준·낙하·무기 전환은 호스트 왕복 없이 즉시 반응하고, 체력·탄약·인벤토리처럼 "다른 사람이 좌우하는" 값만 매 스냅샷마다 호스트 값으로 동기화됩니다. 위치는 살짝 어긋나면 부드럽게, 많이 어긋나면(착지 직후 등) 즉시 보정합니다. 봇·다른 플레이어·총알처럼 완전히 호스트 쪽 데이터인 것들은 스냅샷 사이 구간을 매끄럽게 보간해서 그려, 스냅샷 주기(70ms)마다 뚝뚝 끊기지 않게 했습니다.
- **낙하**: 매치가 시작되면 모두(호스트+게스트) 같은 지도를 보고 낙하 지점을 고릅니다. 게스트는 좌표를 `input/{uid}/dropRequest`로 보내고, 호스트가 이를 감지해 그 위치에 낙하산으로 착지하는 캐릭터를 생성합니다.
- **인원 채우기**: 대기실에서 호스트가 봇 숫자를 직접 입력할 수 있고(인원이 바뀔 때마다 "10명 채우기 기준"으로 자동 제안되다가, 직접 입력하면 그 값을 그대로 씀), 아무것도 안 건드리면 그 자동 제안값이 그대로 쓰입니다.
- **추방**: 호스트는 대기실에서 참가자 옆 "추방" 버튼으로 내보낼 수 있습니다. 밴은 아니라서 같은 방 코드로 다시 들어올 수 있습니다.
- **알려진 한계**: 호스트가 매치 도중 탭을 닫으면 게스트는 일정 시간(`HOST_STALE_MS`) 후 "연결 끊김" 화면으로 넘어가지만, 호스트 마이그레이션(다른 사람이 이어받기)은 지원하지 않습니다. 끝난 매치의 방 데이터도 자동으로 삭제되지 않습니다(장시간 운영 시 Cloud Functions로 정리하는 걸 권장).

## 현재 구현된 기능

- 4000x4000 월드, 장애물(엄폐물)이 있는 맵 — 몸을 숨기면 다른 사람 화면에서 이름표와 캐릭터가 안 보이는 덤불(가까이 다가가면 다시 보임, 봇도 동일하게 적용), 사각 고리 모양으로 배치되어 빙글빙글 돌며 추격/도주할 수 있는 컨테이너 구역
- 낙하 지점을 직접 선택해 낙하산으로 착지하며 시작(착지 전엔 무적, 공격/루팅 불가) — 10초 안에 고르지 않으면 맵 정중앙으로 자동 낙하
- 사망 시 폭발 이펙트와 함께 보유 무기/탄약/의료품이 주변에 흩뿌려져 다른 유닛이 주울 수 있음(내용물은 여전히 열어보기 전까진 알 수 없음)
- 오프라인(봇 19명)과 온라인(실제 플레이어 + 부족한 인원은 봇) 두 가지 매치 모드
- 기본 무기는 주먹(무제한, 근접, 살구색 주먹 두 개로 표현되며 공격 시 앞으로 뻗는 애니메이션)
- 내용물을 알 수 없는 보급 상자: 근처에 머무르면 모래시계가 다 떨어질 때까지(약 2.5초) 열리고, 그 전에 자리를 뜨면 진행도가 초기화됨
- 인벤토리 시스템: 상자에서 얻은 무기/의료품은 바로 장착되지 않고 보관되며, 숫자키 1~4로 무기 전환(각 무기의 탄약은 전환해도 유지), 5로 의료품 사용 — 화면 하단 슬롯 바에서 보유/장착 상태 확인 가능(봇은 자동으로 더 강한 무기를 장착하고 체력이 낮으면 의료품 사용)
- 시간에 따라 축소되는 안전지대(블루존)와 존 밖 피해
- 체력바, 탄약, 생존자 수, 미니맵 HUD, 약 1.8배 확대된 카메라 시야
- 승리/패배 판정, 호스트/게스트 각자의 개인 사망(관전 계속) 처리, 재시작 — 사망 후에는 WASD로 카메라를 자유롭게 움직이며 남은 경기를 관전 가능

## 폴더 구조

```
src/
  core/       Game.js(오프라인+호스트 시뮬레이션), GuestView.js(게스트 렌더링 전용), Camera.js, Input.js
  entities/   플레이어/봇/총알/근접공격 (Unit.js가 공통 로직 담당, melee.js는 주먹 타격 판정)
  render/     drawUnit.js — 호스트의 실제 캐릭터와 게스트가 받은 스냅샷을 같은 코드로 그리는 공용 렌더러
  world/      GameMap.js(장애물/덤불/컨테이너 구역 생성), SafeZone.js, Loot.js
  ui/         HUD·미니맵(HUD.js), 낙하 지점 선택(DropSelect.js), 온라인 로비(Lobby.js)
  network/    firebase.js(초기화/인증), RoomService.js(방/로비/입력/스냅샷 프로토콜), RemoteInputAdapter.js(호스트가 게스트 입력으로 Player를 그대로 재사용하게 해주는 어댑터), firebaseConfig.js
  utils/      상수, 수학 유틸
```
