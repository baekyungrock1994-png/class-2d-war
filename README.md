# 2D War Royale

배틀그라운드(PUBG) 스타일 2D 배틀로얄 프로토타입. 순수 HTML5 Canvas + JavaScript(ES 모듈), 빌드/개발 서버는 Vite 사용.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저가 뜨면 "게임 시작" → 지도에서 낙하 지점 클릭 → "낙하 시작". WASD로 이동, 마우스로 조준, 좌클릭으로 공격(기본은 주먹), R로 재장전, 숫자키 1~4로 보유 무기 전환, 5로 의료품 사용.

## 현재 구현된 기능

- 4000x4000 월드, 장애물(엄폐물)이 있는 맵
- 낙하 지점을 직접 선택해 낙하산으로 착지하며 시작(착지 전엔 무적, 공격/루팅 불가)
- 봇 19명과 대결하는 오프라인 싱글플레이 매치
- 기본 무기는 주먹(무제한, 근접, 살구색 주먹 두 개로 표현되며 공격 시 앞으로 뻗는 애니메이션)
- 내용물을 알 수 없는 보급 상자: 근처에 머무르면 모래시계가 다 떨어질 때까지(약 2.5초) 열리고, 그 전에 자리를 뜨면 진행도가 초기화됨
- 인벤토리 시스템: 상자에서 얻은 무기/의료품은 바로 장착되지 않고 보관되며, 숫자키 1~4로 무기 전환(각 무기의 탄약은 전환해도 유지), 5로 의료품 사용 — 화면 하단 슬롯 바에서 보유/장착 상태 확인 가능(봇은 자동으로 더 강한 무기를 장착하고 체력이 낮으면 의료품 사용)
- 시간에 따라 축소되는 안전지대(블루존)와 존 밖 피해
- 체력바, 탄약, 생존자 수, 미니맵 HUD, 약 1.8배 확대된 카메라 시야
- 승리/패배 판정 및 재시작

## 폴더 구조

```
src/
  core/       게임 루프, 카메라(줌/팬), 입력 처리 (Game.js, Camera.js, Input.js)
  entities/   플레이어/봇/총알/근접공격 (Unit.js가 공통 로직 담당, melee.js는 주먹 타격 판정)
  world/      맵, 안전지대, 루팅 아이템
  ui/         HUD·미니맵(HUD.js), 낙하 지점 선택 화면(DropSelect.js)
  network/    NetworkManager.js — Firebase 연동 지점 (현재는 스텁)
  utils/      상수, 수학 유틸
```

## Firebase 연동 계획

`src/network/NetworkManager.js`에 다음 순서로 연동 예정:

1. `npm install firebase`
2. Firebase 프로젝트 생성 후 Realtime Database(빈번한 위치 갱신에 적합) 또는 Firestore 초기화
3. 매치/로비 모델 설계: `matches/{matchId}/players/{uid}`에 각 클라이언트가 자신의 상태(x, y, 방향, 체력, 무기)를 주기적으로 기록
4. 로컬 `Bot`을 다른 유저의 `RemotePlayer`로 교체 — AI 대신 네트워크로 받은 상태로 위치/애니메이션만 갱신
5. 안전지대 축소, 루팅 스폰, 승패 판정 등 "권위 있는 상태"는 호스트 클라이언트 또는 Cloud Function 한 곳에서만 관리해 치팅 방지
6. 인증은 Firebase Authentication(익명 로그인으로 시작 가능)

지금 구조는 `Game`이 `NetworkManager`를 직접 몰라도 되게 분리되어 있어서, 위 단계는 `network/`와 `main.js` 연결부만 건드리면 됩니다.
